# Images for the ev_charger pull requests

Screenshots and animations shown in the descriptions of the `ev_charger`
pull requests (ADNPolymerase/ha-appliance-card#27): the first version, the animations, and
bidirectional charging. They were rendered in Chromium from the card file of
the branch each pull request comes from.

This branch only hosts the images. It shares no history with `main` and is
not meant to be merged.
